# Driver Drowsiness Detection: A Computer Vision Tutorial

CS663 Computer Vision, Project 1, by Swathi Pallikala.

Live site: https://pallikalas.github.io/Driver-Drowsiness-Detection-Tutorial/

An interactive web tutorial on detecting driver drowsiness from camera video using eye, mouth, and head-pose analysis (EAR, PERCLOS, MAR, head pose), with a quiz and an annotated bibliography.
