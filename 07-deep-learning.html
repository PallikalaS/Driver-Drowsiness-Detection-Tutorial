Deep Learning Approaches

Neural networks learn eye and face patterns directly from images instead of relying on measurements and thresholds designed by people.

Listen to this page

Section 6 ended with a limitation: a traditional classifier can only learn from the features people design, and those features inherit every error in the landmarks. Deep learning removes that bottleneck. Given enough labeled images, a network discovers its own features, including subtle ones nobody thought to measure.

CNN-based drowsiness detection

How a convolutional neural network sees

A convolutional neural network (CNN) is built from layers of small filters, typically 3 × 3 pixels, that slide across the image. Each filter computes a weighted sum of the pixels under it, producing a feature map that lights up wherever the filter's pattern appears. The weights aren't designed by hand; the network learns them during training.

Stacked layers build up a hierarchy. The first layer learns simple edge detectors. The next combines edges into parts, such as the curve of an eyelid or the circle of an iris. Deeper layers respond to whole patterns, such as "an open eye." Pooling layers shrink the feature maps between steps, so later layers see a wider area and the network tolerates small shifts in position.

A full network has dozens of such filters in every layer. Later layers combine their maps so that, for example, an "iris present" pattern only fires when curved edges surround a dark center, which happens for the open eye and not the closed one.

Eye-state classification

The most direct use of a CNN replaces the EAR threshold from Section 3. The landmarks are still used, but only to crop a small image around each eye; a CNN then decides whether the crop shows an open or a closed eye. Because the network judges the eye's appearance rather than six points, it is less thrown off by an awkward head angle or a slightly misplaced landmark. The open/closed decisions then feed the same consecutive-frame and PERCLOS logic as before.

Here is that network in a few lines of Keras. It is small enough to train on a laptop and run in real time on a phone:

from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    keras.Input(shape=(64, 64, 1)),             # grayscale eye crop
    layers.Conv2D(16, 3, activation="relu"),     # 62x62x16: edges
    layers.MaxPooling2D(),                       # 31x31
    layers.Conv2D(32, 3, activation="relu"),     # 29x29x32: lid and iris parts
    layers.MaxPooling2D(),                       # 14x14
    layers.Conv2D(64, 3, activation="relu"),     # 12x12x64: whole-eye patterns
    layers.GlobalAveragePooling2D(),             # one number per filter
    layers.Dropout(0.3),                         # reduces overfitting
    layers.Dense(1, activation="sigmoid"),       # probability the eye is closed
])
model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
model.fit(train_eyes, train_labels, validation_data=(val_eyes, val_labels), epochs=15)

Combining landmarks and CNNs

Many recent systems mix both worlds. Safarov et al. built a real-time framework that combines facial landmark tracking with a CNN to detect blinking and yawning [8]; a later study reports its eye-based fatigue detection at 95.8% accuracy [3]. Zambrano et al. take a similar hybrid path: landmark-based EAR, MAR, and head pose for drowsiness, with a lightweight MobileNetV2 CNN running alongside in real time to recognize emotions [3].

Whole-face detectors: YOLO

A different strategy skips landmarks entirely. An object detector such as YOLO ("You Only Look Once") looks at the whole frame once and outputs boxes with class labels. Trained with face boxes labeled "awake" or "drowsy," it learns every visible cue at once, including closed eyes, yawning, and a drooping head, rather than only the eye measurements [6].

Herath et al. compared seven YOLO versions on images from the UTA Real-Life Drowsiness Dataset, all trained the same way: 50 epochs at 640 × 640 pixels, starting from weights pre-trained on a general image dataset [6]. Their results show the classic deep learning trade-off between accuracy and size:

Read these numbers with care. The study split individual frames randomly into training, validation, and test sets [6]. Neighboring video frames of the same person look almost identical, so a random frame split can place near-copies of test images in the training set, which tends to make results look better than they would on a new driver. Section 8 covers this issue and how to avoid it.

Learning patterns over time

A CNN looking at a single frame faces the same problem as a single EAR value: it can't tell a blink from the start of a microsleep, because both look identical in one frame. Drowsiness unfolds over seconds, so the strongest deep learning systems look at sequences:

  • CNN + LSTM: a CNN turns each frame into a feature vector, and a Long Short-Term Memory network reads the sequence, remembering what happened a moment ago. It learns on its own that a closure lasting 40 frames means something different from one lasting 5.
  • 3D CNNs: filters that extend across time as well as space, so a single filter can respond to "eyelids closing slowly."
  • Transformers: instead of reading frames strictly in order, self-attention lets the model directly compare any frame or image region with any other, which captures long-range patterns. Hassan et al. applied transformer architectures to real-time driver drowsiness detection [9].

A CNN + LSTM needs only a few more lines than the eye classifier above: reuse the CNN (without its final layer) on every frame of a one-second clip, then let an LSTM read the results.

backbone = keras.Model(model.input, model.layers[-3].output)   # CNN up to pooling

clip = keras.Input(shape=(30, 64, 64, 1))           # 30 frames = 1 second
x = layers.TimeDistributed(backbone)(clip)          # one feature vector per frame
x = layers.LSTM(64)(x)                              # read the sequence
drowsy = layers.Dense(1, activation="sigmoid")(x)   # probability of drowsiness
sequence_model = keras.Model(clip, drowsy)

Traditional methods versus deep learning

AspectTraditional (landmarks + rules or classifiers)Deep learning (CNN, YOLO, CNN + LSTM)
Training dataNone for rules; hundreds of labeled windows for classifiersThousands of labeled images or clips
Accuracy (one shared test)EAR rule: 0.812 precision, 0.82 recall [6]YOLO: 0.920–0.954 precision, 0.904–0.978 recall [6]
HardwareAny CPU, including phonesGPU to train; small models run on phones
Robustness to head pose, glasses, lightingWeak with fixed thresholds [6]Better, if the training data includes these conditions
ExplainabilityHigh: "PERCLOS was 22%"Low: hard to say why the network decided
Failure modePredictable: wrong threshold for a personLess predictable: conditions unlike the training data

When to choose which. Choose a landmark-and-rules approach for a quick, explainable prototype on modest hardware, or when there's no labeled data. Choose deep learning when accuracy matters most and representative training data is available, and pick a small model (like a nano YOLO or a MobileNet) if it must run on a phone. In practice the best systems are often hybrids: landmarks for fast, interpretable measurements, plus a CNN to confirm eye state when the geometry is unreliable.

Key takeaways

  • CNNs learn their own filters, from edges to whole-eye patterns, instead of relying on hand-designed measurements.
  • Eye-state CNNs replace the EAR threshold; whole-face detectors like YOLO learn eyes, yawns, and head pose at once.
  • In one comparison, YOLO models beat an EAR rule (precision up to 0.954 vs. 0.812), but random frame splits can inflate such results.
  • Drowsiness is temporal: CNN + LSTM and transformer models look at sequences, not single frames.
